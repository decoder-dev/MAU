## 📖 Описание

Комплексная система мониторинга и управления сетевым оборудованием, разработанная для Мурманского арктического университета. Приложение поддерживает автоматическое переключение между серверной (MySQL) и локальной (SQLite) базами данных, обеспечивая непрерывную работу даже при отсутствии подключения к серверу.

## ✨ Features

### 🔧 Основные возможности

- **Мониторинг устройств** - Автоматическое отслеживание статуса всех сетевых устройств (роутеры, коммутаторы, серверы, принтеры и др.)
- **Автоматическая проверка** - Ping-проверка доступности устройств каждые 5 минут
- **История изменений** - Полная история изменений статусов устройств
- **Заявки на обслуживание** - Система создания и управления заявками на обслуживание
- **Статистика и отчеты** - Детальная статистика по устройствам и экспорт данных
- **Геолокация** - Отображение устройств на карте с координатами

### 🔐 Безопасность

- **Система ролей** - Администратор и обычный пользователь
- **MD5 хеширование** - Безопасное хранение паролей
- **Аудит действий** - Логирование всех операций пользователей
- **Защита данных** - Защита от удаления критичных данных

### 💾 Работа с данными

- **Онлайн/Офлайн режимы** - Автоматическое переключение между серверной и локальной БД
- **Синхронизация** - Автоматическая синхронизация данных при восстановлении подключения
- **Экспорт** - Экспорт данных в CSV формат
- **Резервное копирование** - Автоматическое сохранение данных локально

## 🛠️ Технологии

## 🚀 Installation

### 1. Установка .NET 8.0 Desktop Runtime

Скачайте и установите .NET 8.0 Desktop Runtime с официального сайта:
https://dotnet.microsoft.com/download/dotnet/8.0

### 2. Установка MySQL (опционально)

Если планируете использовать серверную базу данных:

1. Установите MySQL Server 8.0: https://dev.mysql.com/downloads/mysql/
2. Создайте базу данных:
   ```sql
   CREATE DATABASE NetworkMonitoringDB CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
3. Выполните SQL скрипт для создания таблиц:
   ```bash
   mysql -u root -p < DATABASE_SETUP.sql
   ```

### 3. Сборка проекта

```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/network-monitoring-system.git
cd network-monitoring-system

# Восстановите зависимости
dotnet restore

# Соберите проект
dotnet build --configuration Release

# Запустите приложение
dotnet run
```

### 4. Первый запуск

При первом запуске автоматически создастся:
- ✅ Администратор системы (логин: `admin`, пароль: `admin`)
- ✅ Тестовый пользователь (логин: `user`, пароль: `user`)
- ✅ Локальная офлайн база данных SQLite
- ✅ Начальные данные (8 тестовых устройств)

**⚠️ ВАЖНО:** После первого входа обязательно измените пароль администратора!

## 📖 Usage

### Вход в систему

**Учетные данные по умолчанию:**
- **Администратор:** `admin` / `admin`
- **Пользователь:** `user` / `user`

### Основные функции

#### Управление устройствами

1. Откройте раздел **📡 Устройства**
2. Используйте фильтры для поиска устройств по типу, статусу или названию
3. Двойной клик по устройству открывает детальную информацию
4. Администраторы могут добавлять, редактировать и удалять устройства

#### Заявки на обслуживание

1. Откройте раздел **🔧 Заявки на обслуживание**
2. Нажмите **➕ Создать заявку**
3. Выберите устройство и заполните форму заявки
4. Администраторы могут назначать исполнителей и изменять статусы

#### Статистика

1. Откройте раздел **📊 Статистика**
2. Просмотрите общую статистику по устройствам и заявкам
3. Экспортируйте данные в текстовый формат

### Настройка подключения к БД

1. Откройте **⚙️ Настройки** → вкладка **База данных**
2. Заполните параметры подключения:
   - Сервер MySQL
   - Порт (по умолчанию: 3306)
   - Название базы данных
   - Имя пользователя и пароль
3. Нажмите **Проверить подключение**
4. Сохраните настройки и перезапустите приложение

## 🔄 Работа в офлайн режиме

Приложение автоматически переходит в офлайн режим, если:
- Нет подключения к MySQL серверу
- Сервер недоступен по сети
- Неверные параметры подключения

В офлайн режиме:
- ✅ Все данные сохраняются в локальную SQLite базу
- ✅ Все операции записываются в очередь синхронизации
- ✅ При восстановлении подключения автоматически синхронизируются все данные
- ✅ Статус подключения отображается в нижней панели главного окна

## 🐛 Troubleshooting

### Проблема: Не удается подключиться к базе данных

**Решение:**
1. Проверьте, запущен ли MySQL сервер
2. Проверьте параметры подключения в настройках приложения
3. Убедитесь, что база данных `NetworkMonitoringDB` создана
4. Проверьте права доступа пользователя MySQL
5. Проверьте, не блокируется ли порт 3306 файрволом

### Проблема: Приложение работает в офлайн режиме

**Решение:**
1. Проверьте подключение к MySQL серверу (ping, telnet на порт 3306)
2. Проверьте настройки подключения в разделе "Настройки"
3. Приложение автоматически синхронизирует данные при восстановлении подключения

### Проблема: Ошибка при создании пользователя

**Решение:**
1. Убедитесь, что логин уникален
2. Проверьте, что пароль содержит минимум 4 символа
3. Проверьте формат email (если указан)
4. Убедитесь, что вы вошли как администратор
